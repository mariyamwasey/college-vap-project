# Expense Tracker - My Money Diary

A MERN Stack Project for BCA VAP

## About This Project
This project helps users to track their daily income and expenses and see their total balance.

## Features
- Add Income and Expense
- View Total Balance
- Track Daily Transactions
- Simple and Clean Dashboard

## Tech Stack
- MongoDB - Database
- Express.js - Backend
- React.js - Frontend
- Node.js - Runtime

## How to Run
Frontend:
- Open frontend folder and run npm start

Backend:
- Open backend folder and run npm start
